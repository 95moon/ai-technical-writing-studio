# 共享记录的可选模板

可直接用自然的 Markdown 记录，不强制字段或模板。文件名使用实际时间、角色、简短主题和随机短码；在对应共享目录新建文件，不改写他人记录。链接应指向实际可访问的材料。

## 专业交流（discussions）

```markdown
# [主题]

- 日期：[实际日期]
- 角色：[记录者]
- 性质：个人意见 / 待讨论方案 / 研究发现

[独立判断、依据、需要讨论的实际问题]

[所回应的记录、相关书稿或成果位置]
```

## 研究接续（research）

```markdown
# [研究或任务]

- 日期：[实际日期]
- 角色：[记录者]
- 性质：实际状态

[已完成的实质成果及位置]
[影响后续工作的未完成内容、限制]
[下一接续位置；如替代旧状态，链接旧记录]
```

## 已确认决定（decisions）

```markdown
# [决定主题]

- 日期：[实际日期]
- 记录者：[角色]
- 性质：项目负责人已确认
- 确认依据：[真实授权或确认记录]

[确认的方向、范围、权限及必要理由]
[若变更旧决定，链接旧决定]
```

这些是空白格式，不表示已有任何任务、意见或项目负责人决定。无必要时直接写一小段完整的专业说明即可。
