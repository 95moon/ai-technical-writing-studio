# 教材创作工作室｜共享交流区

本目录是可复制到实际项目中的空白协作空间。当前没有任何实际研究记录或已确认的项目决定。

## 共同入口

- [项目共识与决策](decisions/)：只保存项目负责人已明确确认的事项。
- [专业交流](discussions/)：独立专业意见、研究发现、待讨论方案及回应。
- [研究与任务](research/)：真实进展、成果位置和后续接续。

进入实际工作时按需要浏览相关最新记录及其引用的材料。已完成的研究或书稿保存在各自成果目录；共享区主要记录重要认识和链接。无需重复复制全文，也无需固定汇报。

一事一文件。新文件包含实际时间、角色、简短主题及随机短码，例如使用 YYYYMMDD-HHMMSS-微秒_角色_主题_随机码.md 的形式。新建前确认路径不存在；不能安全无覆盖地发布时使用新随机文件名，不覆盖任何已存在记录。回应或修正通过新记录链接原记录。未完成的临时文件不作为正式记录读取。

不同角色独立判断。已确认决策必须有项目负责人确认依据，讨论不自动成为执行授权。共享目录不提供后台执行、自动通知或权限控制，参与者必须具有实际访问能力。各角色不必每次阅读全库。

使用实际项目时，可在本页补充目标读者、重要材料入口和当前阶段；共同入口只在必要时维护，不需要每次更新索引。
